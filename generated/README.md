# Datos y resultados generados

Esta es la carpeta predeterminada de `path`. No es obligatorio copiar aquí ningún archivo para calcularlo todo desde cero: sigue los flags de primera ejecución del README principal.

Los CSV originales, datasets intermedios, matrices PCA, pertenencias fuzzy, informes HTML y pickles quedan excluidos de Git. `.gitignore` permite incluir expresamente algunas tablas pequeñas y el Excel de correlaciones como resultados de referencia.

Si quieres reutilizar resultados históricos, copia los archivos con el nombre exacto esperado por el notebook y verifica que pertenecen al dataset, modelo, target y partición que estás utilizando. Cambiar de directorio no convierte un resultado histórico en un resultado del experimento actual.

Los archivos mostrados en las capturas del autor no se han descargado ni copiado automáticamente. Su clasificación está en `docs/PREPARAR_REPO.md`.
